# Calculator

This is a **scientific calculator** built with **Java** and **JavaFX** for a sleek and interactive GUI experience.

### Features
- Perform **basic arithmetic** (addition, subtraction, multiplication, division) and **advanced operations** (exponents, roots, trigonometry, logarithms).  
- **Built-in unit converter** to quickly switch between common measurement units.  
- **Operation history**: keep track of all your past calculations.
